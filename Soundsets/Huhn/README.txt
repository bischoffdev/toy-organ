======================================================
Soundset: Das Huhn (The Chicken) 🐔
======================================================

In diesem Ordner liegen die beiden Bilder und die Audio-Samples:

1. BILDER:
   - idle.png (oder idle.jpg)   -> Wird angezeigt, wenn keine Taste gedrückt ist (Ruhezustand).
   - active.png (oder active.jpg) -> Wird angezeigt, sobald eine Taste gedrückt wird (Aktiv/Gackern!).

2. AUDIO-SAMPLES (optional):
   Du kannst hier bis zu 12 Audio-Dateien (.wav, .aif, .flac, .ogg) ablegen:
   - 01_C.wav
   - 02_CSharp.wav  (oder C#.wav / Cs.wav)
   - 03_D.wav
   - 04_DSharp.wav  (oder D#.wav / Ds.wav)
   - 05_E.wav
   - 06_F.wav
   - 07_FSharp.wav  (oder F#.wav / Fs.wav)
   - 08_G.wav
   - 09_GSharp.wav  (oder G#.wav / Gs.wav)
   - 10_A.wav
   - 11_ASharp.wav  (oder A#.wav / As.wav)
   - 12_B.wav       (oder B.wav / H.wav)

   Tipp: Wenn du vorerst nur ein einzelnes Gacker-Sample hast, nenne es einfach
   "sample.wav" oder "gaak.wav" – das Plugin pitcht es dann automatisch über
   alle 12 Tasten!
   Solange noch keine Audio-Dateien im Ordner sind, spielt der Toy-Organ-Synthesizer
   automatisch den Orgelton.
